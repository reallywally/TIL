# 6일차. 요율(보험료율)과 보험료지수

> 2단계 금액과 보험료 (계산 로직)

## 오늘의 목표

**요율이 무엇인지**, 그리고 성별·연령·위험등급이 요율을 통해 보험료를 어떻게 바꾸는지 이해한다. 더불어 **보험나이**라는 보험 특유의 나이 개념을 익힌다.

## 1. 요율이란?

**요율(Rate, 보험료율)** 은 **가입금액 단위당 보험료**다.

```
담보 보험료 = 가입금액 ÷ 요율단위 × 요율
```

예: 암진단비 요율이 "1,000만원당 6,100원"이고 가입금액이 3,000만원이면

```
3,000만원 ÷ 1,000만원 × 6,100원 = 18,300원
```

요율은 곧 **"이 위험 1단위를 인수하는 가격"** 이다. 보험 상품의 경쟁력은 결국 이 요율 싸움이다.

### 요율단위에 주의

회사·담보마다 요율단위가 다르다.

- 1,000원당
- 1만원당
- 100만원당
- 1,000만원당
- 1구좌당

**요율값만 보고 비교하면 안 된다.** 반드시 단위와 함께 봐야 한다. 시스템에서도 `요율값`과 `요율단위`를 항상 쌍으로 관리한다.

## 2. 요율을 결정하는 변수들

요율 테이블을 조회하는 키(key)가 곧 "보험료를 바꾸는 요인"이다.

```
요율 = f(담보, 성별, 보험나이, 납입기간, 보험기간, 위험등급, 갱신여부, 특약유형)
```

### 성별

| 담보 | 남성 | 여성 | 이유 |
|---|---|---|---|
| 사망 | 비쌈 | 쌈 | 남성 사망률이 높다 |
| 암(전체) | 비쌈 | 보통 | 중장년 이후 남성 발병률↑ |
| 유방암·자궁암 | - | 여성만 | 성별 특화 담보 |
| 상해 | 비쌈 | 쌈 | 남성 위험직군·활동 비율 |

성별 차이는 **통계에 근거한 차등**이며 차별이 아니다. 다만 최근에는 일부 담보에서 성별 구분을 없애는 흐름도 있다.

### 연령 — 가장 강력한 변수

나이가 한 살 오를 때마다 요율이 오른다. 그것도 **선형이 아니라 지수적으로** 오른다.

암진단비 3,000만원 (20년납 100세만기, 남성) 예시:

| 가입 연령 | 월 보험료 | 30세 대비 |
|---|---|---|
| 30세 | 11,000원 | 1.0배 |
| 40세 | 18,300원 | 1.7배 |
| 50세 | 33,000원 | 3.0배 |
| 60세 | 61,000원 | 5.5배 |

"보험은 하루라도 젊을 때"라는 말의 근거가 이것이다. 그리고 시스템 관점에서는, **생년월일 하나만 잘못 입력해도 보험료가 크게 틀어진다**는 뜻이다.

### 위험등급(직업급수)

직업의 위험도에 따라 1~5급(회사별로 상이)으로 나누고, 급수가 높을수록 요율이 올라간다. 주로 **상해 담보**에 영향을 준다.

| 급수 | 예시 직업 | 상해담보 요율 배수 |
|---|---|---|
| 1급 | 사무직, 교사 | 1.0 |
| 2급 | 영업직, 요리사 | 1.3 |
| 3급 | 생산직, 운전기사 | 1.8 |
| 4~5급 | 건설현장, 어선원 | 2.5 이상 or 인수거절 |

질병 담보는 직업 영향이 거의 없다. 12일차에서 자세히 다룬다.

### 납입기간·보험기간

- 보험기간이 길수록 → 요율 상승 (더 오래 보장하니까)
- 납입기간이 짧을수록 → 요율 상승 (같은 돈을 빨리 걷으니까)

## 3. 보험나이 — 반드시 알아야 할 함정

**보험나이(보험연령)** 는 만나이도 아니고 세는나이도 아니다.

> 계약일 기준으로 만나이를 구하되, **6개월 미만은 버리고 6개월 이상은 1년을 올린다.**

### 계산 예시

1985년 3월 10일생이 2026년 9월 23일에 가입하는 경우

```
만나이 = 41세 6개월 13일
→ 6개월 이상 경과 → 41 + 1 = 보험나이 42세
```

1985년 12월 1일생이 2026년 9월 23일에 가입하는 경우

```
만나이 = 40세 9개월 22일
→ 6개월 이상 → 보험나이 41세
```

1985년 6월 1일생이 2026년 9월 23일에 가입하는 경우

```
만나이 = 41세 3개월 22일
→ 6개월 미만 → 보험나이 41세
```

### 왜 중요한가

- **생일 전후로 보험료가 달라진다.** 며칠 차이로 보험나이가 1살 올라가면 보험료가 수천 원 오른다. "며칠 안에 청약하세요"라는 권유의 근거다.
- **설계 시점과 청약 시점이 다르면 보험료가 달라질 수 있다.** 설계서는 설계일 기준, 실제 계약은 청약일/성립일 기준이다.
- **가입 가능 연령 판정도 보험나이로 한다.** "만 15세~65세 가입 가능"에서 그 나이는 보험나이다.

시스템에서는 보험나이 계산 함수를 **공통 모듈로 딱 하나만** 만들어야 한다. 화면마다 따로 구현하면 반드시 불일치가 난다.

## 4. 보험료지수

**보험료지수**는 "이 상품의 보험료가 순수 위험보험료 대비 몇 %인가"를 보여주는 지표다.

```
보험료지수 = (영업보험료 ÷ 순보험료) × 100
```

- 지수 100 → 사업비가 전혀 없는 상태 (현실에 없음)
- 지수 130 → 순보험료의 1.3배를 내고 있음 = 사업비 비중 약 23%

상품공시에 의무 표기되는 항목이며, **소비자가 상품 간 사업비 수준을 비교**할 수 있게 하는 장치다. 지수가 낮을수록 고객에게 유리한 상품이다.

### 비슷한 다른 '지수'들과 혼동 주의

- **보험료지수**: 사업비 수준 지표 (위)
- **위험률 상대도(할증지수)**: 표준체 대비 위험도. 200%면 표준체의 2배 위험 → 보험료 할증 (15일차)
- **요율 배수**: 직업급수 등에 곱해지는 계수

세 가지가 실무에서 다 "지수"라고 불려서 혼선이 잦다. 문맥으로 구분해야 한다.

## 5. 시스템 관점

```
요율 테이블 (RATE_TABLE)
  ─ PK: 담보코드 + 요율버전 + 성별 + 보험나이 + 납입기간 + 보험기간 + 위험등급
  ─ 요율값, 요율단위
  ─ 적용시작일, 적용종료일
```

실무 포인트:

1. **조회 키가 7~8개**라 인덱스 설계가 중요하다. 설계 화면은 요율을 수십~수백 번 연속 조회한다.
2. **없는 조합은 "가입 불가"를 의미한다.** 요율이 없다는 건 회사가 그 조건을 안 받는다는 뜻이다. 에러가 아니라 **인수 불가 처리**로 연결해야 한다.
3. **보험나이 계산은 공통 유틸로 단일화.** 기준일(설계일/청약일/책임개시일)을 파라미터로 받게 만든다.
4. **요율 스냅샷 저장.** 계약 담보에 사용된 요율값과 버전을 저장해 재현 가능하게 한다.

## 오늘의 정리

- 요율 = 가입금액 단위당 보험료, 반드시 **요율단위와 함께** 봐야 한다
- 요율은 담보 × 성별 × 보험나이 × 납기 × 보기 × 위험등급으로 결정된다
- 연령의 영향이 가장 크고, 지수적으로 증가한다
- **보험나이**는 만나이에서 6개월 반올림 → 며칠 차이로 보험료가 바뀐다
- 보험료지수는 사업비 수준 지표이며, 할증지수·요율배수와 혼동하지 말 것
- 요율 조회 키가 없으면 에러가 아니라 인수 불가다
