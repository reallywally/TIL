# 14일차. 고지의무와 사전 인수 판단

> 4단계 언더라이팅 연결 (인수 심사와의 접점)

## 오늘의 목표

**고지의무**가 무엇이고 위반 시 어떤 일이 벌어지는지 이해한다. 그리고 설계 단계에서 무엇을 미리 거르고, 무엇을 심사로 넘겨야 하는지 판단 기준을 세운다.

## 1. 고지의무란?

> 계약자·피보험자는 계약 체결 시 회사가 서면으로 질문한 **중요한 사항**을 **사실대로 알려야 한다.**

정식 명칭은 **계약 전 알릴 의무**다. 상법 제651조에 근거한다.

### 왜 필요한가

보험은 **정보 비대칭**이 극심한 계약이다. 고객은 자기 건강을 알지만 회사는 모른다. 이미 암 진단을 받은 사람이 숨기고 가입하면 보험 제도 자체가 무너진다.

그래서 법이 고객에게 **진실 고지 의무**를 지우고, 위반 시 강한 제재를 둔다.

## 2. 무엇을 고지해야 하나

청약서의 고지사항 질문 항목(일반심사 기준 예시):

| 구분 | 질문 |
|---|---|
| 최근 3개월 | 의사로부터 진찰·검사를 통해 입원·수술·재검사를 받았거나 권유받은 적 |
| 최근 3개월 | 마약·혈압강하제·신경안정제 등 상시 복용 |
| 최근 1년 | 의사의 진찰·검사를 통해 추가검사(재검사)를 받은 적 |
| 최근 5년 | 입원·수술·계속 7일 이상 치료·30일 이상 투약 |
| 최근 5년 | 10대 질병(암, 백혈병, 고혈압, 당뇨, 심근경색, 협심증, 뇌졸중, 간경화, 에이즈, 정신질환) 진단·치료 |
| 현재 | 직업, 운전 여부, 위험한 취미, 음주·흡연, 임신 여부 |
| 여성 | 임신 여부 |

### 중요한 원칙 — "질문한 것만"

고지의무는 **수동적 의무**다.

- 회사가 **서면으로 질문한 것**에만 답하면 된다
- 묻지 않은 것을 스스로 찾아 말할 의무는 없다
- 구두로만 물은 것은 원칙적으로 고지 대상이 아니다

그래서 청약서 고지 질문 문항의 설계가 곧 회사의 리스크 관리다.

## 3. 고지의무 위반의 효과

### 계약 해지

회사는 계약을 **해지**할 수 있다. 해지되면 보장이 사라진다.

### 보험금 부지급

고지하지 않은 사항과 **인과관계가 있는** 보험금은 지급하지 않는다.

**인과관계가 핵심이다.**

```
고혈압을 숨김 → 뇌출혈 발생 → 인과관계 있음 → 부지급 + 해지
고혈압을 숨김 → 교통사고 골절 → 인과관계 없음 → 보험금은 지급, 계약은 해지
```

### 해지할 수 없는 경우 (제척기간)

회사가 언제까지나 해지할 수 있는 건 아니다.

| 사유 | 해지 불가 |
|---|---|
| 계약 체결일로부터 **3년** 경과 | 해지 불가 |
| 회사가 위반 사실을 안 날로부터 **1개월** 경과 | 해지 불가 |
| 회사가 계약 당시 그 사실을 **알았거나 알 수 있었던** 경우 | 해지 불가 |
| 회사가 건강진단을 실시했고 그로 알 수 있었던 경우 | 해지 불가 |
| 보장개시일로부터 **2년** 경과 후 보험금 지급 사유 미발생 | 해지 불가 |
| 설계사가 고지를 **방해**하거나 부실 고지를 **권유**한 경우 | 해지 불가 |

마지막 항목이 실무에서 중요하다. **"그냥 아니라고 하세요"라고 설계사가 말했다면** 회사는 해지할 수 없다. 이를 **고지 방해**라 하고, 불완전판매의 대표 유형이다.

## 4. 설계 단계에서 무엇을 거를 것인가

13일차에서 본 경계 문제다. 정리하면 이렇다.

### 설계 단계에서 거르는 것 (객관·기계적)

| 항목 | 이유 |
|---|---|
| 연령 미달·초과 | 명확한 숫자 비교 |
| 성별 불일치 담보 | 명확 |
| 직업급수 인수불가 | 코드 비교 |
| 가입금액 범위·배수 | 숫자 |
| 담보 조합 규칙 위반 | 룰 |
| 자사 한도 초과 | 조회 가능 |
| 최저 보험료 미달 | 계산 |

공통점: **논쟁의 여지가 없고, 심사관 판단이 필요 없다.**

### 심사로 넘기는 것 (주관·판단 필요)

| 항목 | 이유 |
|---|---|
| 병력·현재 치료 중 | 정도의 판단 필요 |
| 타사 계약 합산 한도 | 동의 후 조회 필요 |
| 소득 대비 과다 보장 | 재정 심사 |
| 단기간 다수 가입 | 도덕적 위험 판단 |
| 위험한 취미 | 빈도·수준 판단 |
| 과거 보험금 청구 이력 | 패턴 분석 |

### 그 사이 — 사전 인수 판단 (Pre-UW)

설계 단계에서 **간이 고지 질문**을 받아 힌트를 준다.

```
[설계 화면 하단]
□ 최근 3개월 내 입원·수술·재검사 권유를 받은 적이 있다
□ 최근 5년 내 10대 질병으로 진단·치료받은 적이 있다
□ 현재 복용 중인 약이 있다

→ 하나라도 체크 시:
   "심사 과정에서 보장 조건이 조정되거나 인수가 제한될 수 있습니다.
    간편심사 상품 설계를 함께 검토해보세요."
```

**중요: 이건 고지가 아니다.** 법적 고지의무는 청약서에서만 발생한다. 설계 단계 질문은 어디까지나 **안내용**이다. 이 구분을 시스템 문구에서도 명확히 해야 한다. ("고지사항"이라는 단어를 설계 화면에 쓰면 안 된다.)

### 사전 판단의 가치

| | 사전 판단 없음 | 사전 판단 있음 |
|---|---|---|
| 고객 | 청약·진단 다 거치고 거절 | 미리 알고 대안 선택 |
| 설계사 | 헛수고 | 간편심사 등으로 전환 |
| 회사 | 심사 비용 낭비 | 심사 부하 감소 |

**인수 거절률이 높은 회사일수록 사전 판단 기능의 가치가 크다.**

## 5. 유병자 대안 — 간편심사(유병자) 상품

고지 항목을 대폭 줄인 상품군이다.

```
[3·2·5 간편고지]
  최근 3개월 내 입원·수술·추가검사 권유 여부
  최근 2년 내 입원·수술 여부
  최근 5년 내 암·간경화 등 중대질병 진단 여부
```

특징:

- 질문이 3개뿐 → 고혈압·당뇨 있어도 가입 가능
- 대신 **보험료가 일반심사 대비 1.3~2배**
- 가입 후 1~2년간 보장 감액(50%)이 붙는 경우가 많다

설계 시스템에서는 **일반심사 상품과 간편심사 상품을 나란히 비교 제시**하는 기능이 표준이 되고 있다.

## 6. 시스템 관점

```
사전고지질문 (PRE_UW_QUESTION)
  상품코드, 질문번호, 질문내용, 질문유형,
  체크시_조치코드    ── 경고 / 대체상품제안 / 심사필수표시

설계_사전고지응답 (DESIGN_PRE_UW_ANSWER)
  설계번호, 질문번호, 응답값

청약고지사항 (PROPOSAL_DISCLOSURE)   ← 법적 효력 있는 것
  청약번호, 질문번호, 응답값, 상세내용,
  고지일시, 고지방법(대면/전화/모바일),
  전자서명값
```

### 구현 원칙

1. **설계 응답과 청약 고지를 반드시 분리 저장한다.** 법적 성격이 다르다. 설계 응답을 청약 고지로 자동 복사하면 안 된다. 고객이 청약서에서 직접 다시 답해야 한다.

2. **고지 이력은 변경 불가로 보관한다.** 분쟁 시 증거다. 전자서명·타임스탬프를 함께 저장한다.

3. **고지 방해 방지 장치.** 모바일 청약에서는 고지 항목을 설계사가 대신 입력하지 못하게 막고, 고객 본인 인증 후 직접 입력하게 한다. 이것 자체가 회사의 리스크 관리다.

4. **사전 판단 결과를 설계서에 표시한다.** "심사 결과에 따라 조건이 변경될 수 있음"을 명시해야 나중에 분쟁이 줄어든다.

## 오늘의 정리

- 고지의무 = 계약 전 알릴 의무. **회사가 서면으로 물은 것**에 사실대로 답할 의무
- 위반 시 계약 해지 + 인과관계 있는 보험금 부지급
- 3년 경과, 회사 인지 후 1개월, **설계사의 고지 방해** 등의 경우 해지 불가
- 설계 단계는 **객관·기계적 조건**만 거르고, 건강·재정·도덕적 위험은 심사로 넘긴다
- 사전 인수 판단(Pre-UW)은 법적 고지가 아니라 **안내**다 → 문구·저장을 분리해야 한다
- 유병자는 간편심사 상품이 대안이며, 설계 시 비교 제시가 표준이 되고 있다

3. 설계 단계 간이 질문 응답을 청약서 고지사항으로 그대로 옮기면 안 되는 이유는?
