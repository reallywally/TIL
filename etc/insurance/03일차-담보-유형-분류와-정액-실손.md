# 3일차. 담보 유형 분류 — 정액담보 vs 실손담보

> 1단계 계약의 뼈대 (구조 이해)

## 오늘의 목표

담보를 **지급사유별로** 분류할 수 있고, **정액담보와 실손담보의 근본적인 차이**를 설명할 수 있게 된다. 이 차이는 시스템 설계, 보험금 지급, 중복가입 판단 전부에 영향을 준다.

## 1. 지급사유에 따른 담보 분류

장기인보험 담보는 크게 이렇게 나뉜다.

### 진단담보

**질병이나 상태를 진단받으면** 지급한다. 치료 여부, 비용과 무관하다.

- 암진단비, 유사암진단비
- 뇌혈관질환진단비, 뇌졸중진단비
- 허혈성심장질환진단비, 급성심근경색진단비
- 치매진단비, 파킨슨병진단비

특징: **금액이 크고, 보통 1회 지급으로 끝난다.** 그래서 보험료도 비싸다. 상품 경쟁의 주 전장이다.

### 입원담보

**입원하면** 지급한다. 일당 방식이 일반적이다.

- 질병입원일당, 상해입원일당
- 중환자실입원일당
- 종합병원입원일당

특징: **일수에 비례**한다. "1일 이상", "3일 초과" 처럼 지급 개시일 조건이 붙는다.

### 수술담보

**수술을 받으면** 지급한다.

- 질병수술비, 상해수술비
- 1~5종 수술비 (수술 난이도별 차등)
- 특정수술비(암수술비, 뇌수술비 등)

특징: **수술 분류표**에 따라 지급액이 달라진다. 같은 담보라도 1종 수술은 10만원, 5종 수술은 300만원 식이다.

### 실손담보 (실손의료비)

**실제 쓴 의료비를 보상**한다. 오늘의 핵심 주제.

- 급여 의료비 / 비급여 의료비
- 비급여 3종(도수치료, 주사료, MRI)

### 사망·후유장해 담보

- 일반사망, 재해(상해)사망, 질병사망
- 후유장해(장해율에 비례 지급)

특징: 후유장해는 **장해지급률(3%~100%)에 비례**한다. 가입금액 1억, 장해율 30% → 3,000만원.

### 기타 생활보장 담보

- 골절진단비, 화상진단비
- 배상책임, 벌금, 변호사선임비용(운전자보험)
- 간병인지원일당, 응급실내원비

## 2. 정액담보 vs 실손담보 — 근본적 차이

이것이 오늘 반드시 가져가야 할 개념이다.

### 정액담보 (定額, Fixed Benefit)

> **약속한 금액을 그대로 준다.** 실제 손해액과 무관하다.

암 진단비 3,000만원 가입 → 암 진단 → **무조건 3,000만원**. 치료비가 500만원이든 1억이든 상관없다. 심지어 치료를 안 받아도 준다.

### 실손담보 (實損, Indemnity)

> **실제 발생한 손해를 메워준다.** 손해액을 넘을 수 없다.

실손의료비 5,000만원 가입 → 의료비 300만원 발생 → **300만원에서 자기부담금을 뺀 금액**을 준다. 가입금액 5,000만원은 "상한"일 뿐이다.

### 비교표

| 구분 | 정액담보 | 실손담보 |
|---|---|---|
| 지급액 | 가입금액 그대로 | 실제 지출액 한도 내 |
| 영수증 | 필요 없음 | 반드시 필요 |
| 가입금액의 의미 | 지급액 | 보상 한도 |
| 중복가입 | **가능** (각각 다 받음) | **의미 없음** (비례분담) |
| 이득 가능성 | 있음 | 없음(이득금지 원칙) |
| 자기부담금 | 없음 | 있음 (보통 20%) |
| 대표 담보 | 암진단비, 입원일당 | 실손의료비 |

### 중복가입 — 실무에서 가장 중요한 차이

**정액담보**: A사 암진단비 3,000만원 + B사 암진단비 3,000만원 → 암 진단 시 **6,000만원 전액 수령**. 그래서 회사들은 **가입한도**로 총액을 통제한다. (11일차)

**실손담보**: A사 실손 + B사 실손 → 의료비 300만원 발생 → **총 300만원을 두 회사가 나눠서** 부담한다(비례보상). 두 개 들어도 받는 돈은 똑같다. 보험료만 두 배로 나간다.

→ 그래서 실손은 **1인 1계약**이 원칙이고, 가입설계 시 **기존 실손 보유 여부 확인**이 필수 체크 항목이다.

## 3. 손해보험 특유의 개념 — 이득금지 원칙

실손담보의 근거가 되는 원칙이다.

> 보험으로 이득을 볼 수는 없다. 손해를 메우는 데까지만 보상한다.

이 원칙 때문에 실손담보에는 다음 장치들이 붙는다.

- **자기부담금**: 20% 정도는 본인이 낸다 → 과잉진료 억제
- **비례보상**: 중복가입 시 나눠서 부담
- **보상한도**: 연간/1회당 상한

반대로 **정액담보는 이득금지 원칙의 예외**다. 사람의 생명·신체는 금전으로 평가할 수 없다는 논리(인보험의 특성)로, 중복 수령이 허용된다. 그래서 정액담보는 보험사기의 표적이 되고, 이 때문에 **가입한도 관리와 언더라이팅**이 중요해진다.

## 4. 시스템 관점

```
담보기본 (COVERAGE_MASTER)
  담보코드,
  담보명,
  담보유형코드      ← 진단/입원/수술/실손/사망/장해/기타
  지급방식코드      ← 정액(FIXED) / 실손(INDEMNITY) / 비례(RATIO)
  지급횟수제한      ← 1회한 / 연1회 / 무제한
  지급단위          ← 총액 / 1일당 / 1회당 / 장해율비례
  면책기간, 감액기간
```

`지급방식코드` 하나가 이후 로직 전체를 가른다.

- **정액** → 가입한도 체크 필요, 타사 계약 합산 필요, 지급 시 금액 계산 단순
- **실손** → 중복가입 체크 필요, 비례보상 계산 필요, 지급 시 영수증·자기부담금 계산 복잡
- **비례(장해)** → 장해지급률 테이블 참조 필요

가입설계 화면에서도 실손 담보는 별도 영역으로 빠지는 경우가 많다. 보험료 산출 방식도, 한도 체크 방식도 다르기 때문이다.

## 오늘의 정리

- 담보는 지급사유별로 진단/입원/수술/실손/사망·장해/기타로 나뉜다
- **정액담보**는 약속 금액을 그대로 주고, **실손담보**는 실제 손해만큼만 준다
- 정액은 중복가입 시 다 받지만, 실손은 나눠 받는다 → 실손은 1인 1계약
- 실손의 근거는 **이득금지 원칙**, 정액은 그 예외
- 시스템에서는 `지급방식` 코드 하나가 한도 체크·보험료 산출·지급 로직을 전부 가른다
