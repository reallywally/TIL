# 4일차. 납입과 보장의 시간축 — 납입기간·보험기간·만기, 갱신형 vs 비갱신형

> 1단계 계약의 뼈대 (구조 이해)

## 오늘의 목표

보험 계약의 **시간 개념** 세 가지(납입기간·보험기간·만기)를 구분하고, **갱신형과 비갱신형**이 설계와 시스템에 어떤 차이를 만드는지 이해한다.

## 1. 두 개의 서로 다른 시간

보험에는 **성격이 다른 두 개의 기간**이 동시에 흐른다.

```
납입기간 : 돈을 내는 기간       (내가 주는 것)
보험기간 : 보장을 받는 기간     (회사가 주는 것)
```

이 둘은 **같을 수도, 다를 수도 있다.** 초보자는 이 둘을 같은 것으로 착각하는 경우가 많은데, 실제 상품 대부분에서 다르다.

### 납입기간 (납입만기)

보험료를 **내는 기간**이다. 표기 방식은 두 가지다.

- **기간형**: 10년납, 20년납, 30년납
- **연령형**: 60세납, 70세납 (그 나이까지 납입)
- **전기납**: 보험기간 내내 납입 (보험기간 = 납입기간)

### 보험기간 (보장기간, 보험만기)

보장을 **받는 기간**이다. 역시 두 가지 표기.

- **기간형**: 10년만기, 20년만기
- **연령형**: 80세만기, 90세만기, 100세만기
- **종신**: 죽을 때까지

### 조합해서 읽기

상품설명서에서 이런 표기를 본다.

```
20년납 100세만기
```

읽는 법: **20년 동안 보험료를 내고, 100세까지 보장받는다.**

즉 40세에 가입했다면 60세까지 납입하고, 그 후 40년간은 **돈을 안 내면서 보장만 받는다**. 이것이 장기인보험의 전형적인 구조다.

| 표기 | 의미 |
|---|---|
| 20년납 20년만기 | 20년 내고 20년 보장 (=전기납) |
| 20년납 100세만기 | 20년 내고 100세까지 보장 |
| 60세납 80세만기 | 60세까지 내고 80세까지 보장 |
| 10년납 10년만기 갱신형 | 10년마다 다시 계산해서 계속 |

## 2. 납입기간이 짧을수록 보험료는 비싸다

당연한 이야기지만 시스템 관점에서 중요하다.

동일 보장(100세만기 암진단비 3,000만원)을 40세 남성이 가입할 때:

| 납입기간 | 월 보험료 | 총 납입액 |
|---|---|---|
| 10년납 | 약 34,000원 | 408만원 |
| 20년납 | 약 19,000원 | 456만원 |
| 30년납 | 약 14,500원 | 522만원 |

- **월 부담**은 길게 낼수록 적다
- **총액**은 짧게 낼수록 적다 (이자·사업비 때문)

설계 상담의 단골 주제다. "월 부담이냐 총액이냐"를 고객 상황에 맞춰 잡는 것이 설계자의 역할이다.

## 3. 갱신형 vs 비갱신형 — 오늘의 핵심

### 비갱신형

> 가입 시점의 보험료가 **납입기간 내내 그대로** 유지된다.

- 40세 가입 시 월 19,000원 → 60세까지 계속 19,000원
- 처음엔 비싸게 느껴지지만 나중에 유리
- 나이가 들어도 보험료가 오르지 않음

### 갱신형

> 일정 주기(1년/3년/5년/10년, 보통 10년 또는 15년)마다 **보험료를 다시 계산**한다.

- 처음엔 싸다
- 갱신할 때마다 나이가 들었으므로 보험료가 **오른다**
- 70대, 80대에는 감당 못 할 수준이 되기도 한다

### 보험료 추이 비교 (암진단비 3,000만원, 40세 가입 예시)

| 연령 | 비갱신형(20년납) | 갱신형(10년갱신) |
|---|---|---|
| 40~49세 | 19,000원 | 8,000원 |
| 50~59세 | 19,000원 | 17,000원 |
| 60~69세 | **0원** (납입완료) | 38,000원 |
| 70~79세 | **0원** | 85,000원 |
| 80~89세 | **0원** | 190,000원 |

갱신형의 함정이 여기서 보인다. 초기 보험료만 보고 가입하면 노후에 **보장이 가장 필요할 때 보험료를 못 내서 해지**하게 된다.

### 왜 갱신형이 존재하나?

- 실손의료비처럼 **위험률 예측이 어려운 담보**는 갱신형이 아니면 상품을 만들 수 없다 (의료기술·수가가 계속 변함)
- 초기 보험료를 낮춰 **가입 문턱을 낮출 수 있다**
- 보험사 입장에서는 **위험을 계약자에게 전가**할 수 있다

### 설계 시 판단 기준

| 담보 성격 | 권장 |
|---|---|
| 평생 필요한 핵심 보장(암·뇌·심장) | 비갱신형 |
| 실손의료비 | 갱신형 외 선택지 없음 |
| 일정 기간만 필요한 보장(자녀 성장기 등) | 갱신형도 합리적 |
| 보험료 예산이 빠듯할 때 | 갱신형으로 시작 후 전환 검토 |

## 4. 계약 하나 안에 시간축이 여러 개다

**가장 중요한 실무 포인트.**

1일차에서 "담보마다 값이 다르다"고 했는데, 기간도 마찬가지다.

| 담보 | 납입기간 | 보험기간 | 갱신 |
|---|---|---|---|
| 주계약(상해사망) | 20년납 | 100세만기 | 비갱신 |
| 암진단비 | 20년납 | 100세만기 | 비갱신 |
| 뇌혈관질환진단비 | 20년납 | 90세만기 | 비갱신 |
| 실손의료비(급여) | 전기납 | 1년만기 | **1년 갱신** |
| 질병입원일당 | 10년납 | 10년만기 | **10년 갱신** |

한 계약 안에 비갱신 담보와 갱신 담보가 섞여 있다. 그래서 이런 일이 생긴다.

- 10년 뒤 갱신 담보만 보험료가 올라서 **총 보험료가 바뀐다**
- 90세에 뇌혈관 담보만 만기 소멸하고 나머지는 남는다
- "이 계약 만기가 언제예요?"라는 질문에 단일 답이 없다

## 5. 시스템 관점

```
계약담보 (CONTRACT_COVERAGE)
  계약번호, 담보코드,
  납입기간구분   ── 기간형/연령형/전기납
  납입기간값     ── 20(년) or 60(세)
  납입만기일     ── 계산된 실제 날짜
  보험기간구분   ── 기간형/연령형/종신
  보험기간값     ── 100(세)
  보험만기일     ── 계산된 실제 날짜
  갱신여부       ── Y/N
  갱신주기       ── 1/3/5/10/15 (년)
  갱신차수       ── 0회차, 1회차...
  최종갱신종료일 ── 갱신은 보통 상한이 있다(예: 100세까지만)
```

주의할 점:

1. **구분값과 실제 날짜를 둘 다 저장한다.** "100세만기"는 사람마다 날짜가 다르므로, 계약 시점에 실제 날짜로 계산해서 박아둔다.
2. **갱신은 무한하지 않다.** "10년갱신, 100세만기"는 100세까지 10년마다 갱신한다는 뜻이다. 갱신 종료 시점 관리가 필요하다.
3. **갱신 시 보험료 재계산 로직**이 별도로 필요하다. (8일차에서 자세히)
4. **계약 단위 만기 = 담보 만기의 MAX**로 계산하는 경우가 많다. 대푯값일 뿐이라는 점을 잊지 말 것.

## 오늘의 정리

- 납입기간(내는 기간)과 보험기간(보장받는 기간)은 다른 개념이다
- "20년납 100세만기" = 20년 내고 100세까지 보장
- 비갱신형은 보험료 고정, 갱신형은 주기마다 인상
- 실손은 구조상 갱신형일 수밖에 없다
- 한 계약 안에 담보별로 서로 다른 시간축이 섞여 있다
- 시스템은 기간 구분값 + 계산된 실제 날짜를 함께 관리해야 한다

## 스스로 확인하기

1. "30년납 100세만기"로 35세에 가입하면, 몇 세까지 보험료를 내고 몇 년간 무납입 보장을 받나?
2. 갱신형이 초기 보험료가 싼데도 위험한 이유는?
3. "이 계약의 만기일을 하나로 정하라"는 요구가 들어오면 어떻게 계산해야 할까?
