# 8일차. 갱신 보험료의 재계산

> 2단계 금액과 보험료 (계산 로직)

## 오늘의 목표

갱신 시점에 보험료가 **어떤 기준으로 다시 매겨지는지** 이해하고, 갱신이 시스템에서 왜 별도 프로세스로 다뤄지는지 파악한다.

## 1. 갱신이란 무엇인가

4일차에서 배운 갱신형을 다시 보자.

> 보험기간이 끝나면 **동일한 조건으로 계약을 다시 이어가는 것**. 단, 보험료는 그 시점 기준으로 다시 계산한다.

여기서 중요한 두 가지 성질:

### ① 자동갱신이다

고객이 별도로 신청하지 않아도 **자동으로 갱신**된다. 거절 의사를 밝혀야 갱신되지 않는다. 그래서 갱신 안내(통지) 의무가 법으로 정해져 있다.

### ② 심사 없이 갱신된다

**이것이 갱신형의 진짜 가치다.** 그동안 암에 걸렸든 건강이 나빠졌든, 갱신 시에는 재심사(언더라이팅)를 하지 않는다. 그냥 갱신된다.

만약 심사를 다시 한다면 아픈 사람은 전부 탈락할 것이다. 갱신형은 "보험료는 오르지만 자격은 유지된다"는 거래다.

## 2. 갱신 시 보험료가 다시 매겨지는 기준

```
갱신 보험료 = 가입금액 × 갱신시점 요율(갱신시점 보험나이, 성별, 갱신주기, 위험등급)
```

즉 **처음 가입할 때와 똑같은 방식으로, 나이만 바뀌어서 다시 계산**한다.

### 바뀌는 것

| 항목 | 변화 |
|---|---|
| **보험나이** | 갱신주기만큼 증가 (10년갱신이면 +10세) |
| **적용 위험률** | 갱신 시점의 최신 위험률 적용 |
| **요율 버전** | 그동안 개정된 요율 적용 가능 |

### 바뀌지 않는 것

| 항목 | 유지 |
|---|---|
| 가입금액 | 그대로 |
| 보장 내용 | 그대로 (약관 변경분은 예외) |
| 직업급수 | 통보 없으면 기존 유지 |
| 건강 상태 | 반영 안 함 (재심사 없음) |

### 계산 예시

40세 남성, 질병입원일당 3만원, 10년만기 10년갱신

| 갱신차수 | 시점 | 보험나이 | 월 보험료 |
|---|---|---|---|
| 최초 | 2026년 | 40세 | 4,500원 |
| 1차 갱신 | 2036년 | 50세 | 8,200원 |
| 2차 갱신 | 2046년 | 60세 | 16,000원 |
| 3차 갱신 | 2056년 | 70세 | 33,500원 |
| 4차 갱신 | 2066년 | 80세 | 71,000원 |

가입금액은 3만원으로 그대로인데 보험료만 15배가 되었다. 이것이 갱신형의 실체다.

## 3. 보험료가 오르는 두 가지 원인

갱신 보험료 상승은 **두 요인의 곱**이다.

### ① 연령 증가 (확정적)

나이가 들면 위험률이 올라간다. 피할 수 없다.

### ② 위험률 자체의 변경 (불확정적)

의료 환경 변화로 **같은 나이의 위험률 자체가 바뀔 수 있다.**

- 암 진단 기술 발달 → 진단율 상승 → 암 위험률 상승
- 의료수가 인상 → 실손 손해율 상승 → 실손 보험료 인상
- 반대로 치료법 개선으로 위험률이 내려가는 담보도 있다

실손보험료가 갱신 때마다 크게 오르는 뉴스가 나오는 이유가 ②다. 실손은 1년 갱신이라 매년 위험률 변동이 직접 반영된다.

**설명할 때 이 둘을 분리해서 말해야 한다.** "나이가 들어서"와 "손해율이 올라서"는 다른 이야기이고, 고객 민원의 핵심도 대개 ②다.

## 4. 갱신 관련 실무 규칙

### 갱신 상한

갱신은 무한하지 않다.

```
"10년만기 10년갱신, 100세 만료"
```

→ 100세가 되면 더 이상 갱신되지 않고 소멸한다. 이 **최종 만료 시점**을 시스템이 관리해야 한다.

### 갱신 거절권

- **고객**: 갱신을 거절할 수 있다 (해지 효과)
- **회사**: 원칙적으로 갱신을 거절할 수 없다. 단 상품 판매 중지 시 예외 규정이 있을 수 있다

### 갱신 안내 의무

갱신일 이전에 **변경될 보험료를 서면/전자적으로 안내**해야 한다. 통상 만기 30~60일 전. 이 안내가 없으면 분쟁 소지가 된다.

### 갱신 시 무심사 vs 재심사

- 원칙: **무심사**
- 예외: 갱신 시 가입금액을 **증액**하려면 증액분에 대해 심사한다
- 직업이 바뀌어 위험등급이 올라간 경우 통보 의무가 있고, 미통보 시 보험금 비례 삭감 가능

## 5. 시스템 관점

갱신은 **배치 프로세스**로 처리된다.

```
[갱신 대상 추출 배치]  만기 60일 전 담보 추출
        ↓
[갱신 보험료 산출]     갱신시점 보험나이 계산 → 요율 조회 → 보험료 계산
        ↓
[갱신 안내 발송]       문자/우편/앱 알림
        ↓
[갱신 거절 접수]       고객이 거절하면 제외
        ↓
[갱신 확정 배치]       만기일에 실행
        ↓
[계약담보 갱신 처리]   갱신차수 +1, 보험기간 갱신, 보험료 갱신
```

### 데이터 모델

```
계약담보 (현재 상태)
  계약번호, 담보코드, 갱신차수, 보험료, 보험기간시작/종료, ...

계약담보이력 (GOVERNANCE)
  계약번호, 담보코드, 갱신차수,
  적용시작일, 적용종료일, 보험료, 적용요율, 적용보험나이
```

**이력 테이블이 반드시 필요하다.** 현재 상태만 들고 있으면 "3년 전에 얼마 냈었는지"를 답할 수 없고, 민원·분쟁 대응이 불가능하다.

### 구현 시 함정

1. **갱신 시점 보험나이를 어떻게 계산하나?**
   - 갱신일 기준으로 다시 계산한다. 단순히 "기존 나이 + 갱신주기"로 하면 보험나이 반올림 때문에 1년 어긋나는 경우가 생긴다. 반드시 **갱신일 기준 재계산**.

2. **납입면제 상태의 갱신** (7일차 연계)
   - 면제 대상 담보라면 갱신 후 보험료도 0
   - 면제 대상이 아니면 정상 갱신 + 정상 청구

3. **요율 버전 선택**
   - 갱신 시점에 유효한 요율 버전을 쓴다. 최초 계약 시 버전이 아니다.
   - 단, 상품 판매 중지로 요율이 더 이상 관리되지 않는 경우 **최종 버전 고정** 규칙이 필요하다.

4. **갱신 실패 처리**
   - 요율 테이블에 해당 나이 요율이 없다면? (예: 90세 요율 미관리)
   - 갱신 상한에 도달했다면?
   - → 소멸 처리 + 안내

5. **계약 총 보험료 재계산**
   - 담보 하나가 갱신되면 계약 전체 보험료가 바뀐다. 계약 헤더의 합계 금액과 수금 정보를 함께 갱신해야 한다.

## 오늘의 정리

- 갱신 = 자동 + 무심사로 계약을 이어가되, 보험료만 다시 계산
- 갱신 보험료 = 가입금액 × **갱신시점 나이 기준 요율**
- 상승 요인은 ① 연령 증가 ② 위험률 자체 변경 — 둘을 구분해 설명해야 한다
- 갱신에는 상한(최종 만료 시점)이 있다
- 시스템은 추출 → 산출 → 안내 → 확정의 배치 흐름 + **이력 테이블**이 핵심
- 보험나이는 갱신일 기준으로 **재계산**해야 한다

## 스스로 확인하기

1. 갱신형의 가장 큰 장점(고객 입장)은 보험료가 싼 것일까, 다른 것일까?
2. "기존 보험나이 + 10"으로 갱신 나이를 계산하면 왜 틀릴 수 있나?
3. 실손보험료가 매년 오른다는 뉴스에서, 상승 원인을 둘로 나눠 설명해보자.
