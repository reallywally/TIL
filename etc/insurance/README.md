## 이 커리큘럼을 관통하는 7가지 원칙

1. **담보가 최소 단위다** — 금액·기간·보험료·조건이 모두 담보에 붙는다
2. **모든 마스터에 유효기간을 붙인다** — 나중에 추가할 수 없다
3. **계약에는 스냅샷을 남긴다** — 마스터가 바뀌어도 계약은 흔들리지 않는다
4. **규칙은 코드가 아니라 데이터다** — 상품 추가마다 배포하면 안 된다
5. **검증은 한 군데에서, 여러 시점에** — 공통 엔진 + 반복 호출
6. **결과에는 항상 근거를 담는다** — 규제 산업이며 분쟁이 잦다
7. **이력을 남긴다** — 수십 년짜리 계약이다
