# 19일차. 설계서(가입설계 결과물)의 구성

> 5단계 상품과 프로세스 (전체 그림)

## 오늘의 목표

가입설계의 최종 산출물인 **설계서**에 무엇이 들어가야 하고, 어떤 값이 검증되어야 하는지 파악한다.

## 1. 설계서란?

> 가입설계의 결과를 고객에게 보여주는 **문서**.

명칭이 여러 개다.

| 명칭 | 성격 |
|---|---|
| 가입설계서 | 보험료와 보장 내역 |
| 상품설명서 | 상품의 구조·위험 설명 (법정 서류) |
| 보험안내자료 | 총칭 |

법적으로는 **보험안내자료**에 해당하며, 보험업법상 기재 사항과 금지 사항이 정해져 있다.

### 법적 성격 다시 확인

13일차에서 배운 대로 설계서는 **구속력이 없다**. 그러나:

- **설명의무 이행의 증거**가 된다
- 불완전판매 분쟁 시 핵심 증거다
- 허위·과장 기재 시 제재 대상이다

그래서 "대충 만드는 출력물"이 아니라 **법적 리스크 관리 문서**로 다뤄야 한다.

## 3. 설계서에서 검증되어야 하는 값들

설계서 출력 직전에 시스템이 확인해야 할 체크리스트다.

### 필수 검증 항목

| 검증 | 내용 |
|---|---|
| **위배 없음** | E등급 위배가 0건인가 (16일차) |
| **보험료 합계 일치** | 담보별 보험료 합 = 표시된 총 보험료 |
| **최저 보험료 충족** | 상품 최저 보험료 이상인가 |
| **주계약 존재** | 주계약이 포함되어 있는가 |
| **보험나이 유효** | 설계일 기준으로 재계산했는가 |
| **요율 버전 유효** | 설계일에 유효한 요율인가 |
| **상품 판매 가능** | 판매중지되지 않았는가 |
| **담보 관계 정합** | 부가필수/배타 규칙 모두 충족 |
| **한도 충족** | 자사 한도 이내인가 |
| **필수 문구 포함** | 법정 기재사항이 모두 출력되는가 |

### 자주 터지는 버그

1. **합계 불일치**: 담보별로 절사한 뒤 더한 값과, 합계를 따로 계산한 값이 다르다. (5일차) → 계산 로직을 한 곳으로 통일할 것.

2. **설계일과 출력일이 다름**: 어제 저장한 설계를 오늘 출력했는데 보험나이가 바뀌었다. → **출력 시점에 재검증**하고, 필요하면 재계산 후 안내.

3. **담보 정렬 순서 뒤죽박죽**: 주계약이 중간에 끼어 있거나 관련 담보가 흩어져 있다. → 상품담보의 `정렬순서` 관리.

4. **면책·감액 문구 누락**: 담보 마스터에 조건은 있는데 출력 템플릿이 안 읽는다. → 조건이 있으면 **반드시 출력되도록 강제**.

5. **갱신 예시 보험료 오류**: 미래 요율을 현재 요율로 계산. → 현재 요율 기준 추정임을 명시.

## 4. 시스템 관점

### 설계서 생성 구조

```
설계 데이터 (DB)
     ↓
[검증 모듈]  ── 전체 규칙 재검증 (16일차)
     ↓  통과
[조립 모듈]  ── 출력용 데이터 구성
     │          · 담보 목록 정렬
     │          · 면책/감액 조건 수집
     │          · 갱신 예시 계산
     │          · 해지환급금 조회
     │          · 법정 문구 삽입
     ↓
[렌더링]     ── PDF / HTML / 모바일 뷰
     ↓
[보관]       ── 출력 이력 저장 (필수)
```

### 출력 이력 보관

```
설계서출력이력
  출력번호, 설계번호, 출력일시, 출력자,
  출력형식, 전달방법(출력/이메일/문자/앱),
  문서해시,        ── 위변조 검증용
  보관파일경로
```

**왜 보관하나:**

- 분쟁 시 "그때 고객에게 준 문서가 이것"을 증명
- 설명의무 이행 증빙
- 감독당국 검사 대응

보험업법상 보험안내자료는 일정 기간 보존 의무가 있다. 설계서를 화면에서만 보여주고 안 남기면 나중에 증명할 방법이 없다.

### 템플릿 관리

- 법정 문구는 **템플릿으로 분리**하고 버전 관리한다
- 법 개정 시 문구가 바뀐다 → 어느 시점에 어떤 문구로 출력했는지 추적 가능해야 한다
- 상품별로 다른 안내가 필요하므로 상품 속성에 따라 조립되어야 한다

## 오늘의 정리

- 설계서는 법적 구속력은 없지만 **설명의무 이행의 증거**다
- 필수 구성: 기본정보 / 보험료 / 담보별 상세 / 면책·감액 / 갱신 안내 / 납입면제 / 해지환급금 / 경고문구
- 담보별 상세표에 1~18일차 개념이 전부 들어간다
- 출력 전 **전체 재검증**이 필수이며, 합계 일치·필수문구·요율 유효성을 확인한다
- **출력 이력을 반드시 보관**한다 (분쟁·감독 대응)
- 법정 문구는 템플릿으로 분리해 버전 관리한다
