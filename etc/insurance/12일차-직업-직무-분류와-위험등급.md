# 12일차. 직업·직무 분류와 위험등급

> 3단계 가입조건과 규칙 (가입설계의 핵심)

## 오늘의 목표

**직업급수(위험등급)** 가 무엇이고, 이것이 인수 가능 여부와 보험료를 **동시에** 어떻게 바꾸는지 이해한다.

## 1. 왜 직업을 묻는가

보험 청약서에서 직업은 필수 기재 항목이다. 이유는 단순하다.

> **직업이 사고 확률을 크게 바꾸기 때문이다.**

사무직과 고층 건설 근로자의 상해 사고율은 몇 배 차이가 난다. 같은 보험료를 받으면 사무직이 손해를 보고 회사는 고위험군에서 적자를 본다.

## 2. 직업급수(위험등급) 체계

한국 손해보험 업계는 보통 **1~3급** 또는 **1~5급** 체계를 쓴다. (회사마다 다름)

| 급수 | 명칭 | 예시 직업 | 상해 위험 |
|---|---|---|---|
| 1급 | 비위험(사무직) | 사무원, 교사, 의사, 공무원, 주부 | 낮음 |
| 2급 | 준위험 | 영업사원, 요리사, 미용사, 판매원 | 보통 |
| 3급 | 위험 | 생산직, 운전기사, 배달원, 농업 | 높음 |
| 4급 | 고위험 | 건설현장직, 용접공, 벌목 | 매우 높음 |
| 5급 | 초고위험 | 어선원, 고압선 작업, 폭발물 취급 | 인수 제한 |

### 급수를 정하는 기준

- 작업 환경 (실내/실외, 고소/지상)
- 기계·장비 사용 여부
- 이동 거리와 수단
- 유해물질 노출
- 업계 통계상 재해율

## 3. 직업급수가 바꾸는 것 — 두 가지

### ① 보험료 (요율 배수)

주로 **상해 담보**에 곱해지는 계수가 달라진다.

상해사망 1,000만원 기준 예시:

| 급수 | 요율 배수 | 월 보험료 |
|---|---|---|
| 1급 | 1.00 | 1,200원 |
| 2급 | 1.35 | 1,620원 |
| 3급 | 1.90 | 2,280원 |
| 4급 | 2.80 | 3,360원 |

**질병 담보(암·뇌·심장)는 직업 영향이 거의 없다.** 암 발생률은 직업과 상관관계가 약하기 때문이다. (일부 유해물질 노출 직군은 예외)

이것이 초보자가 놓치는 포인트다. "직업급수가 올라가면 보험료가 다 오른다"가 아니라 **"상해 담보만 오른다"** 가 정확하다.

### ② 인수 가능 여부

급수가 높으면 아예 못 받는 담보가 생긴다.

```
상해사망후유장해   : 1~4급 가입 가능, 5급 인수 불가
상해입원일당      : 1~3급 가입 가능
골절진단비        : 1~3급, 4급 이상은 심사
암진단비         : 전 급수 가능 (질병담보)
```

**한도도 급수에 따라 달라진다.**

```
상해사망 가입한도
  1급 : 3억원
  2급 : 2억원
  3급 : 1억원
  4급 : 5천만원
  5급 : 인수불가
```

즉 직업급수는 **보험료(가격)와 인수(자격)를 동시에 흔드는** 유일한 변수다. 연령도 둘 다 건드리지만, 직업은 여기에 **변경 가능성**까지 더해져서 더 복잡하다.

## 4. 직업 분류 체계의 실제

### 직업코드 체계

업계 표준 직업분류표(보험개발원 제공)를 기반으로 각 사가 자체 코드를 운영한다.

```
직업코드   직업명              급수   비고
--------------------------------------------
01010     일반사무원            1
01020     회계사무원            1
03110     자동차운전기사(택시)   3
03120     자동차운전기사(화물)   3
05210     건축목공              4
07130     원양어선선원          5    인수불가
```

### 직업 vs 직무 — 중요한 구분

같은 "건설회사 직원"이라도

- **사무 담당** → 1급
- **현장 관리** → 3급
- **직접 시공** → 4급

**소속 회사(직업)가 아니라 실제 하는 일(직무)이 기준**이다. 그래서 청약서에서 "회사명 / 부서 / 담당업무"를 구체적으로 묻는다.

시스템에서도 직업코드 선택만으로 끝내면 안 되고, **구체적 직무 기재 항목**을 함께 받아야 한다.

### 겸업 처리

투잡인 경우 **높은 급수를 적용**한다. 낮 사무직 + 밤 대리운전이면 3급.

### 무직·주부·학생

- 주부, 학생, 무직 → 통상 1급
- 단 **소득 기반 한도**에서 제약을 받는다 (11일차)

## 5. 직업 변경 — 실무의 핵심 이슈

계약 후 직업이 바뀌면 어떻게 되나?

### 통지의무

> 피보험자가 **직업·직무를 변경한 경우 지체 없이 회사에 알려야 한다.**

이는 약관상 **계약 후 알릴 의무(통지의무)** 다. (14일차의 '계약 전 알릴 의무=고지의무'와 다르다)

### 변경 시 처리

| 변경 방향 | 처리 |
|---|---|
| 낮은 급수 → 높은 급수 | 보험료 증액 또는 차액 정산 |
| 높은 급수 → 낮은 급수 | 보험료 감액 + 차액 환급 |
| 인수불가 급수로 변경 | 해당 담보 해지 또는 계약 해지 |

### 통지하지 않았을 때 — 비례보상

**가장 중요한 지점이다.**

직업 변경을 알리지 않은 상태에서 사고가 나면, 보험금이 **비례 삭감**된다.

```
지급보험금 = 약정보험금 × (변경 전 요율 ÷ 변경 후 요율)
```

예: 1급(요율 1.0)으로 가입 → 4급(요율 2.8)으로 변경했으나 미통지 → 상해사망 1억원 사고

```
1억원 × (1.0 / 2.8) = 3,571만원만 지급
```

6,400만원이 날아간다. 고객에게 반드시 설명해야 하는 내용이고, 설계서와 약관에 명시된다.

## 6. 시스템 관점

```
직업마스터 (JOB_MASTER)
  직업코드, 직업명, 직업분류대/중/소,
  위험등급,              ── 1~5
  유사직업키워드,         ── 검색용
  적용시작일, 적용종료일

담보별직업규칙 (COVERAGE_JOB_RULE)
  담보코드, 위험등급,
  인수가능여부,
  요율배수,
  가입한도금액

계약피보험자
  계약번호, 피보험자,
  직업코드, 직무내용,
  위험등급,              ── 계산 결과를 스냅샷으로 저장
  직업변경이력 → 별도 테이블
```

### 구현 시 고려사항

1. **직업 검색 UX가 중요하다.** 직업코드는 수천 개다. 설계사가 "택시"를 치면 관련 직업이 뜨게 해야 한다. 키워드 매핑 테이블이 필수.

2. **위험등급은 계약에 스냅샷으로 저장한다.** 직업분류표가 개정되어 등급이 바뀌어도, 기존 계약은 가입 당시 등급으로 유지된다.

3. **등급 변경 시 재계산 범위**: 상해 담보만 영향을 받으므로, 전체 보험료를 다시 계산하되 질병 담보는 값이 그대로여야 한다. 이게 안 맞으면 버그다.

4. **직업 변경 이력 관리**: 언제부터 언제까지 어떤 급수였는지 기간 이력이 필요하다. 사고 발생일 기준 급수를 판정해야 비례보상 계산이 가능하다.

5. **설계 시 위험등급 선택이 앞단에 와야 한다.** 직업을 나중에 입력하면 이미 선택한 담보가 인수불가로 바뀌면서 설계가 통째로 무너진다. **입력 순서 설계**가 UX 품질을 좌우한다.

## 오늘의 정리

- 직업급수(위험등급)는 사고 확률의 대리 지표다
- 급수는 **상해 담보의 보험료**와 **인수 가능 여부·한도**를 동시에 바꾼다
- 질병 담보는 직업 영향이 거의 없다
- 기준은 소속 회사가 아니라 **실제 직무**, 겸업은 높은 급수 적용
- 직업 변경은 **통지의무** 대상이고, 미통지 시 보험금이 **비례 삭감**된다
- 시스템은 위험등급 스냅샷 + 변경 이력 + 사고일 기준 판정이 필요하다
