# 7일차. 납입면제

> 2단계 금액과 보험료 (계산 로직)

## 오늘의 목표

**납입면제**가 무엇이고 왜 시스템에서 까다로운지 이해한다. 면제 이후 계약이 어떤 상태가 되는지, 보험료 계산에 어떻게 반영되는지 설명할 수 있게 된다.

## 1. 납입면제란?

> 특정 사건이 발생하면, **그 이후의 보험료를 내지 않아도 보장은 계속 유지**되는 제도.

핵심은 "면제"지 "환급"이나 "해지"가 아니다.

```
              면제사유 발생
                   ↓
   ──────납입────────┼───── 납입 없음, 보장은 계속 ─────→
   가입              면제        원래 납입만기      보험만기
```

### 왜 필요한가

암에 걸린 사람에게 계속 보험료를 내라고 하면, 치료비 부담 때문에 보험을 해지하게 된다. **정작 보장이 필요한 순간에 계약이 사라지는** 역설을 막는 장치다.

고객 입장에서는 강력한 혜택이고, 판매 시 핵심 소구점이다.

## 2. 대표적인 면제 사유

회사·상품마다 다르지만 전형적인 것들:

| 면제 사유 | 설명 |
|---|---|
| 암 진단확정 | 가장 일반적 (유사암은 제외인 경우가 많음) |
| 뇌졸중·급성심근경색 진단 | 2대 질병 |
| 50%이상 후유장해 | 장해율 기준 |
| 80%이상 후유장해 | 더 엄격한 기준 |
| 장기요양 1~2등급 판정 | 노후 대비 상품 |
| 계약자 사망 | 어린이보험에서 부모(계약자) 사망 시 |
| 재해로 인한 장해 | 재해 한정 |

## 3. 초보자가 가장 헷갈리는 포인트 5가지

### ① 면제되는 것은 "앞으로의 보험료"다

이미 낸 보험료는 돌려주지 않는다. 면제 시점 이후 도래하는 보험료만 안 낸다.

### ② 면제 대상 범위가 계약마다 다르다

여기가 진짜 함정이다. 면제가 되면 **무엇이 면제되는가?**

| 유형 | 면제 범위 |
|---|---|
| 전체 면제 | 주계약 + 전 특약 보험료 전부 |
| 주계약만 면제 | 주계약 보험료만, 특약은 계속 납입 |
| 해당 특약만 면제 | 면제사유가 속한 특약만 |
| 갱신형 제외 | 비갱신 담보만 면제, 갱신형은 계속 납입 |

**실손의료비 같은 갱신형 담보는 면제 대상에서 빠지는 경우가 많다.** 갱신할 때마다 새 계약처럼 보험료를 다시 매기기 때문이다. 이 규칙을 놓치면 "면제됐는데 왜 돈이 빠져나가요?" 민원이 발생한다.

### ③ 면제 후에도 보장은 그대로다

면제는 **보장 축소가 아니다.** 보험료만 안 낼 뿐 보장은 100% 유지된다. 만기도 그대로다.

### ④ 면제 후에도 '납입한 것으로 간주'한다

해지환급금 계산, 만기환급금 계산 시에는 **정상 납입한 것으로 처리**한다. 면제됐다고 환급금이 줄어들지 않는다. 회계·적립금 관점에서 이 처리가 중요하다.

### ⑤ 면제사유 담보가 소멸하면?

암진단비 담보로 면제를 받았는데, 그 암진단비 담보가 지급 후 소멸(1회한 지급)한다면? 면제는 **계속 유지**된다. 면제는 담보의 존속과 무관하게, 사건 발생 사실에 근거한다.

## 4. 납입면제와 보험료의 관계 — 설계 단계에서의 영향

납입면제는 **공짜가 아니다.** 회사 입장에서는 받을 돈을 못 받는 것이므로, 그 비용이 보험료에 미리 반영되어 있다.

- 납입면제 기능이 있는 상품은 **요율에 면제 비용이 포함**된다
- 일부 상품은 **납입면제특약**을 별도 담보로 붙인다 → 이 경우 보험료가 눈에 보인다

시스템 설계 시, 이 둘을 구분해야 한다.

| 방식 | 처리 |
|---|---|
| 요율 내재형 | 별도 담보 없음. 요율에 이미 반영. 상품 속성으로 관리 |
| 별도 특약형 | 담보로 존재. 가입 여부 선택 가능. 보험료 별도 계산 |

## 5. 시스템 관점 — 왜 어려운가

납입면제는 **계약 상태를 바꾸는 이벤트**다. 단순 계산이 아니다.

```
계약담보
  ...
  납입면제여부      Y/N
  납입면제일자      2027-05-14
  납입면제사유코드  C01(암진단)
  납입면제전_보험료  18,300원   ← 면제 전 금액을 보존
  현재청구보험료     0원
```

### 구현 시 고려사항

1. **담보별 면제 플래그가 필요하다.** 계약 단위 플래그만 두면 "일부 담보만 면제" 케이스를 표현할 수 없다.

2. **면제 전 보험료를 반드시 보존한다.** 나중에 면제가 취소되거나(무효·취소 사유 발견), 갱신 시 기준이 필요하다.

3. **청구 금액 재계산 배치가 필요하다.** 면제 처리 시점에 이미 다음 달 수금 데이터가 만들어져 있으면 반환 처리를 해야 한다.

4. **과납 반환 로직.** 면제사유 발생일과 면제 처리일 사이에 빠져나간 보험료는 돌려줘야 한다. 면제 효력은 보통 **사유 발생일** 기준이다.

5. **갱신과의 상호작용.** 면제 상태에서 갱신 시점이 오면?
   - 갱신형 담보가 면제 대상이면 → 갱신하되 보험료 0
   - 면제 대상이 아니면 → 정상 갱신, 정상 납입
   - 갱신 자체를 중단하는 상품도 있다

6. **가입설계 단계에서의 표현.** 설계서에는 "납입면제 사유: 암진단확정 시 이후 보험료 납입면제"처럼 **조건을 명시**해야 한다. 금액은 변하지 않지만 고객이 알아야 할 핵심 정보다.

### 상태 전이 다이어그램

```
[정상납입] ──면제사유 발생──> [납입면제]
     │                            │
     │                            ├─ 면제취소(고지의무위반 등) ──> [정상납입]
     ├─ 납입완료 ──> [납입완료]     └─ 보험만기 ──> [만기소멸]
     └─ 실효/해지 ──> [실효]
```

면제 취소 케이스를 빼먹으면 나중에 손댈 수 없는 구조가 된다. 처음부터 **되돌릴 수 있게** 설계해야 한다.

## 오늘의 정리

- 납입면제 = 사건 발생 이후 보험료 면제, **보장은 그대로 유지**
- 면제 범위(전체/주계약/일부/갱신형 제외)가 상품마다 다르다 → 가장 큰 함정
- 면제되어도 납입한 것으로 간주 → 환급금 불이익 없음
- 면제 비용은 요율에 이미 반영되어 있거나 별도 특약으로 존재한다
- 시스템은 **담보별 면제 플래그 + 면제 전 보험료 보존 + 취소 가능 구조**가 필수
- 효력 기준일은 보통 사유 발생일 → 과납분 반환 로직 필요
