# 15일차. 표준체 / 표준미달체 / 할증 · 부담보

> 4단계 언더라이팅 연결 (인수 심사와의 접점)

## 오늘의 목표

심사 결과로 나오는 **조건부 인수**의 종류를 이해하고, 그 결과가 **설계서와 계약에 어떻게 반영되는지** 파악한다.

## 1. 체(體) 분류 — 위험의 등급

언더라이팅은 피보험자를 위험 수준에 따라 분류한다.

| 분류 | 의미 | 처리 |
|---|---|---|
| **우량체(우수체)** | 표준보다 건강 (비흡연, 정상혈압, 정상BMI) | 보험료 **할인** |
| **표준체** | 통계상 평균 위험 | 정상 인수 |
| **표준미달체** | 평균보다 위험 | **조건부 인수** |
| **거절체** | 인수 불가 수준 | 거절 |

### 위험률 상대도

표준체를 100%로 놓고 상대적 위험도를 표시한다.

```
표준체        : 100%
경증 고혈압   : 125%
중증 당뇨     : 250%
암 치료 후 2년 : 400%
```

6일차에서 언급한 "할증지수"가 이것이다. 이 수치가 조건부 인수의 근거가 된다.

## 2. 조건부 인수의 4가지 방법

표준미달체를 그냥 거절하면 시장을 잃는다. 그래서 **조건을 붙여 인수**한다.

### ① 보험료 할증 (Extra Premium)

> **위험이 큰 만큼 보험료를 더 받는다.**

```
표준 보험료 18,300원
할증률 50% 적용
→ 27,450원
```

표기 방식:

| 방식 | 예시 | 설명 |
|---|---|---|
| 백분율 할증 | 표준체의 150% | 위험률에 비례 |
| 정액 할증 | 가입금액 1,000만원당 월 3,000원 추가 | 특정 위험에 적용 |
| 연령 가산 | 실제 나이 + 5세로 계산 | 사망 담보에 흔함 |

**기간 제한 할증**도 있다. "향후 5년간만 할증, 이후 표준 보험료"처럼. 수술 후 회복 중인 케이스에 쓴다.

### ② 부담보 (Exclusion)

> **특정 부위·질병을 보장에서 제외**하고 인수한다.

```
"좌측 무릎 관절 및 그 합병증에 대하여
 계약일로부터 5년간 보장하지 않음"
```

부담보의 구성 요소 세 가지:

| 요소 | 예시 |
|---|---|
| **대상** | 특정 신체 부위 / 특정 질병 / 질병 분류(UPR 코드) |
| **기간** | 전기간 / 5년 / 3년 |
| **범위** | 해당 질병만 / 합병증 포함 |

할증과 부담보의 차이:

| | 할증 | 부담보 |
|---|---|---|
| 보험료 | 오른다 | 그대로 |
| 보장 | 전부 보장 | 일부 제외 |
| 고객 체감 | 비싸다 | 손해 본 것 같다 |
| 적용 | 전신 위험(고혈압, 비만) | 국소 위험(특정 부위 질환) |

일반적으로 **국소적·명확한 병력은 부담보**, **전신적·지속적 위험은 할증**을 적용한다.

### ③ 감액 (Reduction)

> **가입금액을 줄여서** 인수한다.

```
신청: 암진단비 5,000만원
판정: 3,000만원으로 감액 승낙
```

주로 한도 초과(11일차)나 도덕적 위험 우려가 있을 때 쓴다.

**보장 감액**과 혼동 주의. 2일차의 "가입 후 1년 이내 50% 지급"은 모든 계약에 붙는 약관사항이고, 여기 감액은 **심사 결과로 붙는 개별 조건**이다.

### ④ 일부 담보 거절

> 문제가 되는 담보만 빼고 나머지는 인수한다.

```
암진단비        → 거절 (5년 전 암 병력)
뇌혈관질환진단비 → 승낙
상해담보        → 승낙
```

계약은 성립하되 담보 구성이 바뀐다.

### 그 외

- **보류/연기**: "치료 종료 후 1년 뒤 재심사" — 지금은 판단 불가
- **조건부 서류 요청**: 추가 진단서, 검사 결과 제출 시 재판정

## 3. 조건부 인수가 설계서·계약에 반영되는 방식

**여기가 시스템에서 가장 신경 써야 할 부분이다.**

### 흐름

```
[1] 청약 내용 (고객이 신청한 것)
        ↓  심사
[2] 심사 결과 조건 부여
        ↓
[3] 조건 반영한 계약 내용 재산출     ← 보험료가 바뀐다!
        ↓
[4] 고객에게 조건 통지 및 동의 확인   ← 필수
        ↓
[5] 동의 → 계약 성립 / 거부 → 청약 철회
```

**[4]가 법적으로 필수다.** 고객이 신청한 것과 다른 조건으로 계약할 수는 없다. 조건부 승낙은 법적으로 "새로운 청약"에 해당하므로 고객의 승낙이 필요하다.

### 설계서·증권에 표기되어야 하는 것

```
■ 특별조건부 인수 내역

  [보험료 할증]
   대상 담보 : 뇌혈관질환진단비
   할증 사유 : 고혈압
   할증률   : 130%
   할증 기간 : 전기간
   표준보험료 11,200원 → 할증보험료 14,560원

  [부담보]
   대상 담보 : 질병입원일당, 질병수술비
   부담보 대상 : 요추 및 그 합병증
   부담보 기간 : 계약일로부터 5년 (2031-09-23까지)
```

고객이 **무엇이 어떻게 달라졌는지 명확히 알 수 있어야 한다.** 이 표기가 부실하면 나중에 보험금 분쟁에서 회사가 진다.

## 4. 시스템 관점

```
계약특별조건 (CONTRACT_SPECIAL_CONDITION)
  계약번호,
  담보코드,             ── 어떤 담보에 걸리는가 (NULL이면 전체)
  조건유형,             ── 할증 / 부담보 / 감액 / 거절
  조건사유코드,          ── 고혈압, 당뇨, 요추질환...
  할증률,               ── 130 (%)
  할증금액,             ── 정액 할증인 경우
  부담보대상코드,        ── 질병분류코드 or 신체부위코드
  부담보상세,           ── "요추 및 그 합병증"
  적용시작일, 적용종료일, ── 기간 제한 조건
  표준보험료, 조정보험료,  ── 둘 다 보관
  고객동의일시
```

### 구현 시 핵심 고려사항

1. **표준 보험료와 조정 보험료를 둘 다 저장한다.**
   - 기간 제한 할증이 끝나면 표준 보험료로 돌아가야 한다
   - 갱신 시 기준이 필요하다
   - 고객 설명용

2. **부담보 기간 만료 배치가 필요하다.**
   ```
   "5년간 부담보" → 5년 뒤 자동으로 보장이 살아나야 한다
   ```
   이걸 처리하지 않으면 보장이 시작됐는데도 보험금이 안 나간다. 실제로 자주 터지는 사고다.

3. **보험금 지급 시스템과 연동된다.**
   - 청구 건이 부담보 대상 질병인지 판정해야 한다
   - 질병분류코드(KCD) 기반 매칭이 필요하다
   - 부담보 기간 내 사고인지 날짜 판정

4. **조건 변경 시 재계산 범위**
   - 할증은 해당 담보 보험료만 바꾼다
   - 담보 거절은 그 담보를 제거하고 **담보 관계 규칙을 재검증**해야 한다 (10일차)
     - 거절된 담보가 다른 담보의 선행조건이었다면 연쇄 제거가 필요하다
   - 그 결과 최저 보험료 미달이 될 수도 있다 → 전체 규칙 재검증

5. **동의 이력 관리.** 조건 통지 → 동의/거부 → 성립/철회의 상태 흐름과 증빙(전자서명, 녹취)을 보관한다.

## 5. 우량체 할인 — 반대 방향

표준체보다 건강하면 깎아준다.

| 조건 | 할인 |
|---|---|
| 비흡연 (코티닌 검사 음성) | 5~15% |
| 혈압·BMI 정상 | 5~10% |
| 건강검진 결과 우수 | 추가 할인 |
| 건강관리 실천(걸음수 등) | 보험료 캐시백 |

시스템에서는 **할인도 할증과 같은 특별조건 구조**로 관리하면 된다. 부호만 반대다.

## 오늘의 정리

- 위험 수준에 따라 우량체 / 표준체 / 표준미달체 / 거절체로 분류한다
- 조건부 인수 방법: **할증**(보험료↑), **부담보**(보장 일부 제외), **감액**(가입금액↓), **일부 담보 거절**
- 전신 위험은 할증, 국소 병력은 부담보가 일반적
- 조건부 승낙은 **고객 동의가 반드시 필요**하다
- 시스템은 표준/조정 보험료 이중 보관, **부담보 만료 배치**, 지급 시스템 연동, 담보 제거 시 규칙 재검증이 필요하다

## 스스로 확인하기

1. 고혈압이 있는 사람과 3년 전 무릎 수술을 한 사람, 각각 어떤 조건이 붙을 가능성이 높은가?
2. 심사 결과 담보 하나가 거절됐다. 시스템이 추가로 해야 할 일은?
3. "5년간 부담보" 조건을 저장만 하고 만료 처리를 안 하면 어떤 사고가 나나?
