# 5일차. 보험료 산출의 기본 구조 — 영업보험료 = 순보험료 + 부가보험료

> 2단계 금액과 보험료 (계산 로직)

## 오늘의 목표

고객이 내는 보험료가 **어떤 조각들로 이루어져 있는지** 분해할 수 있고, 담보별 보험료가 어떻게 합산되어 최종 보험료가 되는지 이해한다.

## 1. 보험료의 3층 구조

고객이 실제로 내는 돈을 **영업보험료(Gross Premium)** 라고 한다. 이것은 두 조각으로 나뉜다.

```
영업보험료 (고객이 내는 돈)
 ├─ 순보험료 (Net Premium)      ← 보험금 줄 돈
 │   ├─ 위험보험료              ← 사고 나면 줄 돈
 │   └─ 저축보험료              ← 나중에 돌려줄 돈 (있는 상품만)
 └─ 부가보험료 (Loading)         ← 회사 운영비
     ├─ 신계약비                ← 설계사 수당, 심사비
     ├─ 유지비                  ← 계약 관리비
     └─ 수금비                  ── 보험료 수납 비용
```

### 위험보험료

**보험금 지급 재원**이다. 순수하게 "이 위험을 인수하는 데 필요한 돈".

```
위험보험료 = 가입금액 × 위험률
```

40세 남성의 1년간 암 발생률이 0.2%라면, 암진단비 3,000만원의 위험보험료는

```
3,000만원 × 0.002 = 6만원/년 = 5,000원/월
```

이 위험률은 **경험생명표·참조위험률**에서 온다. 보험개발원이 산출해 제공하는 통계다.

### 저축보험료

만기에 돌려줄 돈, 해지환급금의 재원이다.

- **순수보장형(소멸성)**: 저축보험료 없음 → 만기에 한 푼도 안 돌려줌 → 보험료 쌈
- **만기환급형**: 저축보험료 있음 → 만기에 낸 돈 일부/전부 돌려줌 → 보험료 비쌈

같은 보장인데 보험료가 2~3배 차이 나는 이유가 대부분 이것이다.

### 부가보험료

회사가 운영하는 데 드는 비용이다. 통상 영업보험료의 **10~30%** 수준이며, 상품·채널마다 다르다.

- **신계약비**: 가입 첫해에 집중된다. 그래서 초기 해지 시 환급금이 거의 없다.
- **유지비**: 매달 발생
- **수금비**: 자동이체/카드 등 수납 방식에 따라 다름

## 2. 담보별 합산 원리 — 실무의 핵심

**보험료는 계약 단위로 계산되지 않는다. 담보 단위로 계산해서 더한다.**

```
계약 보험료 = Σ (담보별 보험료)
담보별 보험료 = 가입금액 × 담보별 요율 (+ 담보별 부가)
```

실제 계산 예 (40세 남성, 20년납 100세만기):

| 담보 | 가입금액 | 요율(1만원당) | 담보 보험료 |
|---|---|---|---|
| 상해사망후유장해 | 1,000만원 | 0.012 | 1,200원 |
| 암진단비 | 3,000만원 | 0.061 | 18,300원 |
| 유사암진단비 | 600만원 | 0.015 | 900원 |
| 뇌혈관질환진단비 | 2,000만원 | 0.056 | 11,200원 |
| 허혈성심장질환진단비 | 2,000만원 | 0.038 | 7,600원 |
| 질병입원일당 | 3만원/일 | 1,500(만원당) | 4,500원 |
| 질병수술비 | 30만원 | 70(만원당) | 2,100원 |
| **합계** | | | **45,800원** |

여기서 반드시 이해할 것:

1. **각 담보는 완전히 독립적으로 계산된다.** 담보 간 할인·가산은 원칙적으로 없다.
2. **담보 하나를 빼면 그 담보의 보험료만큼만 줄어든다.** 이 선형성 덕분에 설계 시뮬레이션이 가능하다.
3. **요율은 담보마다, 그리고 성별·연령·납입기간·보험기간마다 다르다.** 위 표의 요율은 "40세 남성 20년납 100세만기"에서만 유효하다.

## 3. 보험료 계산의 전체 흐름

```
① 입력: 피보험자 정보(성별/생년월일/직업), 담보별(가입금액, 납입기간, 보험기간)
        ↓
② 보험나이 계산      ← 만나이 아님! (6일차)
        ↓
③ 담보별 요율 조회   ← 요율테이블 (담보 × 성별 × 나이 × 납기 × 보기)
        ↓
④ 위험등급 반영      ← 직업급수에 따른 할증 (12일차)
        ↓
⑤ 담보별 보험료 계산 = 가입금액 / 요율단위 × 요율
        ↓
⑥ 원단위 절사/반올림 ← 회사 규칙
        ↓
⑦ 합산 → 영업보험료
        ↓
⑧ 할인 적용          ← 자녀할인, 건강체할인, 다계약할인 등
        ↓
⑨ 최종 보험료
```

**⑥ 절사 규칙이 은근히 중요하다.** 담보별로 절사한 뒤 합산할지, 합산 후 절사할지에 따라 결과가 몇십 원 달라진다. 설계 시스템과 계약 시스템의 금액이 안 맞는 사고의 단골 원인이다. 회사 표준을 확인하고 **한 군데에 구현**해야 한다.

## 4. 납입주기와 보험료

보험료는 보통 **월납** 기준으로 산출한 뒤, 납입주기에 따라 환산한다.

| 납입주기 | 계산 | 특징 |
|---|---|---|
| 월납 | 기준 | 가장 일반적 |
| 3개월납 | 월납 × 3 × 할인율 | 약간 할인 |
| 6개월납 | 월납 × 6 × 할인율 | |
| 연납 | 월납 × 12 × 할인율 | 할인 폭 가장 큼 |
| 일시납 | 별도 산출 | 전체를 한 번에 |

미리 받을수록 회사가 운용할 수 있으므로 할인해준다.

## 5. 시스템 관점

```
요율 테이블 (RATE_TABLE)
  담보코드, 성별, 보험나이, 납입기간, 보험기간, 위험등급
  → 요율값, 요율단위(1만원당/1천원당 등)
```

이 테이블은 **행이 수백만 건**이 된다. 담보 300개 × 성별 2 × 나이 80 × 납기 5 × 보기 5 = 120만 건. 여기에 위험등급까지 곱해진다.

그래서 실무에서는:

- 요율 조회는 **캐싱**이 필수다
- 설계 화면에서 슬라이더를 움직일 때마다 전체 재계산이 일어나므로 **성능 이슈**가 가장 먼저 터지는 지점이다
- 요율 테이블은 **상품 개정 시 버전 관리**가 필요하다. 계약 시점의 요율로 계산해야 하기 때문에 "적용시작일/종료일" 컬럼이 반드시 들어간다

```
계약담보
  ...
  요율        ← 계산에 쓴 요율을 스냅샷으로 저장
  요율버전    ← 어떤 버전을 썼는지
  보험료
```

**계산 결과뿐 아니라 계산에 쓴 입력값도 저장한다.** 나중에 "이 보험료가 왜 이 금액이냐"는 민원·감사에 답하려면 재현이 가능해야 한다.

## 오늘의 정리

- 영업보험료 = 순보험료(위험 + 저축) + 부가보험료(사업비)
- 위험보험료 = 가입금액 × 위험률, 위험률은 통계에서 온다
- 만기환급형이 비싼 이유는 저축보험료가 들어 있기 때문
- 보험료는 **담보별로 계산해서 합산**한다 — 이 선형성이 설계를 가능하게 한다
- 요율은 담보 × 성별 × 나이 × 납기 × 보기의 조합으로 조회된다
- 절사 규칙과 요율 버전 관리가 실무 버그의 단골 원인

## 스스로 확인하기

1. 같은 암진단비 3,000만원인데 A상품은 2만원, B상품은 5만원이다. 왜 그럴까?
2. 담보 하나를 설계에서 제외하면 보험료가 정확히 그 담보분만큼 줄어드는 이유는?
3. 5년 전에 체결된 계약의 보험료를 재계산해야 한다면, 어떤 요율을 써야 하나?
